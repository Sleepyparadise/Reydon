# 🚀 P3 Superstar Showdown!

An interactive, game-show style web app designed to help Singapore Primary 2 students transition smoothly into Primary 3 across **Mathematics, Science, English (STELLAR), and Chinese (华文)**.

## ✨ Features
- **4 Core MOE P3 Subjects:** Numbers to 10,000, introductory P3 Science process skills, English Synthesis & Cloze, and Chinese measure words & conjunctions.
- **Zero Dependencies:** Pure HTML, CSS, and Web Audio API sound effects in a single `index.html` file.
- **Mobile & Tablet Ready:** Supports Add-to-Home-Screen full-screen mode.

## 🌐 Live Deployment (GitHub Pages)
1. Push `index.html` and `README.md` to your GitHub repository.
2. Go to **Settings** → **Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**, select **`main`** and **`/ (root)`**, then click **Save**.
4. Your live app will be ready at `https://<your-username>.github.io/<repo-name>/` in ~60 seconds.
